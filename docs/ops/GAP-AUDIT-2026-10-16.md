# Notification and communication gap audit - 2026-10-16

Read-only comparison of every point where Helm tells someone something. No app code was changed.
Legend:
- **Working** - works today with no setup (in-app bell, team chat, links, simulated channels).
- **Dormant** - code is built, but it sends nothing until the owner does the setup in the last column.
- **Missing** - not built yet.

Shared owner setups referred to below:
- **WA** = WhatsApp, see `docs/ops/WHATSAPP-SETUP.md` (Meta app, templates, secrets, deploy, `liveChannels.whatsapp`).
- **EMAIL** = Resend: verify the sending domain in Resend, `supabase secrets set RESEND_API_KEY=... RESEND_FROM=...`,
  deploy the mailer, set its `HELM_*_ENABLED=true` + secret, schedule it with pg_cron/pg_net (see `supabase/functions/README.md`).
- **PAY** = Razorpay: per-studio keys via 0117 (`org_payment_accounts`, Vault) or global `RAZORPAY_KEY_ID/SECRET`,
  `RAZORPAY_WEBHOOK_SECRET`, deploy `create-payment-link` + `razorpay-webhook`, flip `liveChannels.pay`
  (see `docs/INTEGRATIONS-WHATSAPP-RAZORPAY.md` Part B).
- **SMS** = MSG91 `MSG91_AUTHKEY`, deploy `send-otp`, flip `liveChannels.sms`.

## What is missing (to build)
1. **Assignment push** - WhatsApp `helm_task_assigned` to the assignee + a system message in the event chat group
   ("X was assigned Y at Z"). In progress by the assign-notify agent (migration 0132). Needs WA live to deliver;
   the bell + chat parts work without it.
2. **"Your link was updated" notice** to crew / vendors when their run-sheet slot, time or location changes
   (not only on first assignment). Needs a de-duplication window so many small edits send one message.
3. **Run-sheet and checklist change notifications** - nothing is raised today.
4. **In-app "Send via Helm WhatsApp" button** - `send-whatsapp` is deployed-ready but no screen calls it; staff
   use `wa.me` links from their own phone instead.
5. **Event reminders to crew / client on WhatsApp** - 0129 deliberately sends bell + chat only.
6. **`helm_task_assigned` on the allowlist** - add to `WHATSAPP_TEMPLATES` secret (or to `DEFAULT_TEMPLATES`
   in `send-whatsapp`) or sends will be refused with "template not allowed".
7. **One notification log screen** for the owner showing sent / delivered / failed / opted-out per channel
   (data exists in `notifications`, `comms_outbox`, `integration_webhook_events`; no single view).
