# Quotes list: tabs, the date filter, smart search and saved views

The **Quotes** page lists every quote and event in your studio. These tools help you find the right one fast.

## Tabs
| Tab | What it shows |
| --- | --- |
| Active | Everything that is still moving |
| In progress | Drafts that don't have a saved quotation yet (only some roles see it) |
| Quotes | Quotes not yet sent or confirmed |
| Sent & confirmed | Sent to the client, or confirmed |
| ⚠ Attention | Things that need you - for example a quote waiting too long |
| Cancelled | Events cancelled with **Cancel event** on the event page |
| Archive | Old and closed events (cancelled events stay here too) |
| Deleted | Removed quotes (only some roles see it) |

Cancelled events are kept out of Active, Quotes, Sent & confirmed and Attention, so your working lists stay clean. Only an admin or event manager can cancel an event, and a reason is asked every time.

## Filter by event date
Next to **All types** there is a date filter (hover text "Filter by event date"). Pick **Any date**, **Today**, **Tomorrow**, **This week** (Monday to Sunday), **This month**, **Next month**, **Next 30 days** or **Past dates**. It uses the date of the event, not the date the quote was last changed.

## Search
- Type a quote code, a client name or a title in **Search code, client, title…**.
- **Smart search**: type a short phrase and press **Enter**. Helm sets the tab, type and date for you and shows what it picked, e.g. **Showing: Cancelled · Wedding · This month**. Examples:
  - `cancelled weddings this month`
  - `confirmed next month`
  - `today`
- Smart search understands tab words (cancelled, attention, overdue, confirmed, sent, archived, deleted, in progress, active), date words (today, tomorrow, this week, this month, next month, next 30 days, past) and your event types. If a phrase has any other words, Helm does a normal search instead.
- Search does not look inside phone numbers, e-mails or amounts - open the client from **Clients** for that.

## Saved views
A view remembers the tab, the type, the date filter and the search text - so "This month's weddings" is one click away.
1. Set the tab and filters you want.
2. In the **Views:** row above the list, press **+ Save view**.
3. Type a name (up to 60 letters) and press **Save view**. Admins are also asked **Share with studio** or **Just me**.
4. Your view appears as a chip. Click it any time.

On your own views, the **⋯** menu has **Update with current filters**, **Rename**, **Set as default** (★ - it opens first), **Share with studio** / **Stop sharing** (admins), and **Delete**. Deleting a view never deletes any quote. Views marked **· studio** were shared by an admin with everyone.

## Who can do what
| Action | Who |
| --- | --- |
| See the Quotes list, tabs, filters, search | Roles that can view **Quotes & workspace** |
| Save, rename, delete your own views | Everyone who sees the list |
| Share a view with the whole studio | Admins |
| Cancel an event | Admin or event manager with edit rights |
