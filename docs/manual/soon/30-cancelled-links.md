What is coming:
- When an event is cancelled, every client link for it (approval, booklet, portal, invitation) stops working at once.
- An admin or event manager can **Restore** a cancelled event; links can then be sent again.
- Every cancel and restore is kept in the event's history with the reason.

Who: admin or event manager.
