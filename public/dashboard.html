👋 Welcome to Helm Events

Everything runs off one event, from first enquiry to final close. Here's the flow and what each area does.

Lead→Discovery→Proposal→Quote→Confirm→Plan→Resources→Ready→Event day→Settle→Close
🎯
Leads & CRM

Capture an enquiry, qualify it on the pipeline, then Convert → to create the event and open its Workspace.Every enquiry sits on the pipeline by stage; open a lead to see its details. CRM keeps every past client; Nurture sends birthday/anniversary greetings.

📋
Quote & Workspace

Each event opens as one Workspace page. Build the floor in 2D/3D, price the Quote, and Confirm it (client approves by OTP/consent/payment).Open it to see the floor plan, the quote and everything planned for the day. The quote code is based on the event date.

🧮
Resources first

Map what the event needs → the app checks in-house Staff & Inventory → flags the gaps → book Vendors/freelancers/rentals only for the gaps. The Calendar catches clashes.

📦
Inventory & accountability

Items are graded A/B/C by value. Check equipment OUT to a person and back IN with a count + sign-off — anything missing shows in the loss report (chairs, mics, walkie-talkies).

🗓
Plan & tasks

Run-sheet, venue & menu, budget vs actuals. Tasks are organised by section (stage, carpets, lighting…); set start times & dependencies (carpet waits for stage), and flag special tasks for reminders.

✅
Readiness → Event day → Close

The Readiness gate goes green only when everything's set. On the day, the Command centre tracks arrivals & checks and a Quality engineer passes/rejects each task. Then Settle payments and Close with the P&L.

👥
Who sees what

Admins set each role's access in Settings → User control — green tick = allowed.Your admin decides what each role can open, so you only see the areas your role uses. So a salesperson sees only Leads & CRM, crew only their own tasks, and so on.
