Client links — auto-expire

Optional. When on, every link you send outside the studio stops working a set number of calendar days (weekends count) after it was sent. It never makes a link last longer: if the usual limit after the event comes first, that one still applies.

Disabled

Off — links follow only the usual limits after the event.

Which links this covers
  • Quote approval link — and the client portal and payment pages it opens (counted from when the link was first created).
  • Payment links — a pay-online link never outlives the approval link it came from.
  • Proposal link — counted from when it was first published.
  • Crew task links — counted from the last time a task was assigned to that person.
  • Invitation websites (and their photos) — counted from when the site was published. Invitations usually go out weeks before the event, so a short limit will switch them off before the day.
When a quote's client link expires (and it was never approved, confirmed or paid)

Only quotes the studio never confirmed, that the client never approved or paid, with no payment or approval on record. Confirmed and paid events never move. A quote you restore stays put for the same number of days.

Links you already sent count from when they were sent, so any older than the limit stop working as soon as you save. Switching this off, or raising the number, makes them work again. To give someone a fresh link, send it again (Send approval link, publish the proposal again, or assign the crew member a task). Anyone opening an expired link sees the usual “this link has expired — please contact the studio for a new one” page.

Quote validity

Every new quote gets a "Valid until" date. Your client sees it on their quote and booklet, gets a reminder before it ends, and after it ends sees "This quote has expired - ask us for an updated one" with a button that tells you. Anyone who can edit quotes can extend a quote with one click.

Read-only: only a studio admin (or someone allowed to edit Settings) can change these.

Hide amounts — privacy PIN

The eye button in the top bar hides every amount on screen while you present to a client. Showing them again needs this 4-digit PIN. It is one PIN for the whole studio, kept on the server as a secure hash. Only studio admins can change it. Until an admin changes it, the PIN is 0000.

Payment schedules

When a client approves a quote, Helm adds your default payment schedule to the event (only when it has none yet - an existing schedule is never changed). Reminders to the client go out only when “Payment reminders” is switched on in Automations. Recording a payment marks every payment it fully covers as paid.

Read-only: your role can view these rates but not change them.

Automatic client messages & WhatsApp

Helm can remind clients about payments, follow up on proposals they opened, warn your team about stock clashes and copy notifications to WhatsApp. Each one is off until you switch it on in Settings → Automations (the one place for every on / off switch); here you set how they work. Messages are sent by the server, never twice, and each one is logged on the event. WhatsApp is used only after you add your studio's WhatsApp number below.
